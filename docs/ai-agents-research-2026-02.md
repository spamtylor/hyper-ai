# AI Agents Research - February 2026

## Overview
AI agents are here and being deployed across contexts varying widely in consequence - from email triage to cyber espionage. Understanding this spectrum is critical for deploying AI safely.

## Key Developments

### Anthropic Research (Feb 2026)
- **Measuring AI Agent Autonomy**: Analysis of millions of human-agent interactions across Claude Code and public API reveals:
  - Claude Code works autonomously for longer - longest-running sessions nearly doubled in 3 months (from under 25 min to over 45 min)
  - Experienced users auto-approve more frequently (20% → 40%+), but interrupt more when needed
  - Agent-initiated stops are important oversight - on complex tasks, Claude Code asks for clarification more than humans interrupt
  - Most agent actions are low-risk/reversible; software engineering ~50% of agentic activity
  - Emerging usage in healthcare, finance, cybersecurity

### OpenAI Research Focus
- **GPT Series**: Fast, versatile, cost-efficient AI for text/image context understanding
- **o Series**: Advanced reasoning models using chain-of-thought for STEM problems
- **Safety**: Learning from human feedback; researching new alignment techniques

### Anthropic Teams
- **Interpretability**: Discover and understand how LLMs work internally
- **Alignment**: Ensure future models remain helpful, honest, harmless
- **Societal Impacts**: Real-world AI usage exploration
- **Frontier Red Team**: Cybersecurity, biosecurity, autonomous systems

## Key Trends
1. **Increasing Autonomy**: Agents running longer before human intervention
2. **Human-AI Collaboration**: New interaction paradigms for managing autonomy/risk
3. **Domain Expansion**: From coding → healthcare, finance, cybersecurity
4. **Oversight Evolution**: Post-deployment monitoring infrastructure needed

## Recommendations (from Anthropic)
- Model developers: Build in autonomy management
- Product developers: Design human-AI interaction paradigms
- Policymakers: Framework for agent oversight
